# Pirate Whirlpool Escape

Interactive web prototype of the ocean-facts pirate board game (MDEI 80 Facts project).

## Play it locally
Just open `index.html` in a browser -- it's a single self-contained file, no build step or server needed.

## Hosted version
Once pushed to GitHub with Pages enabled, this will be live at:
`https://<your-github-username>.github.io/pirate-whirlpool-escape/`
